# To-Do List App 

## Project Description
This is a simple To-Do List application built using Python.
The program allows users to manage their daily tasks through a command-line interface.

Users can add tasks, view all tasks, and delete tasks from the list.

This project helps beginners understand Python lists, loops, user input, and conditional statements.

---

## Features
✔ Add a new task  
✔ View all tasks  
✔ Delete a task  
✔ Simple command-line interface  
✔ Beginner-friendly Python project  

---

## Technologies Used
- Python 3
- Command Line Interface (CLI)
